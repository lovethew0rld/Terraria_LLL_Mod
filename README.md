# 宇宙增幅器 · LLL

> 一个自用向的泰拉瑞亚 tModLoader 模组：把「宇宙增幅器」做成常驻被动，并加入大量便利功能与世界机制开关。

![version](https://img.shields.io/badge/version-3.9.9-blue)
![tModLoader](https://img.shields.io/badge/tModLoader-1.4.4-8A2BE2)
![author](https://img.shields.io/badge/author-LLL-green)

本仓库是模组的**完整源码**，可直接编译，也可用于学习参考。

---

## 简介

模组最初只是给自己用的「作弊小工具」，后来慢慢长成了一个功能集合：

- 一个可自由调数值的**宇宙增幅器**被动（原版是个饰品，现在改成开局直接生效）
- 几个实用物品：初始物品袋、宝物魔镜 / 花之魔镜、NPC 监狱建造器
- 大量**可开关**的游戏机制改动：战利品倍率、合成消耗、斩杀线、无敌帧、容器饰品生效、钓鱼、节日、商店解锁……

所有数值都能在游戏内的模组配置里改，觉得不平衡可以自己调。

## 安装

### 方式一：玩家安装现成 `.tmod`

1. 安装 [tModLoader](https://store.steampowered.com/app/1281930/tModLoader/)（1.4.4 分支）
2. 把 `.tmod` 文件放进 `文档/My Games/Terraria/tModLoader/Mods/`
3. 启动游戏，在「模组」页面启用

### 方式二：从源码编译（开发者）

```powershell
cd "$env:USERPROFILE\Documents\My Games\Terraria\tModLoader\ModSources"
git clone https://github.com/lovethew0rld/Terraria_LLL_Mod.git LLL
```

然后启动 tModLoader → **设置 → 模组 → 开发模组** → 勾选 `LLL` → 点击「构建并重载」（Build + Reload）。

> 编译依赖 `ModSources/tModLoader.targets`，该文件由 tModLoader 自动生成。若缺失，启动一次游戏并进入「开发模组」页面即可生成。

## 宇宙增幅器（核心功能）

默认提供的加成，全部可在配置里改：

| 效果 | 默认值 |
| --- | --- |
| 最终伤害倍率 | ×5 |
| 全局暴击率（近战/远程/魔法/召唤） | +100% |
| 护甲穿透 | +35 |
| 召唤栏位 | +66 |
| 哨兵栏位 | +66 |
| 伤害减免 | +40% |
| 最大生命值 | +100 |
| 最大魔力值 | +100 |
| 法力消耗 | −80% |
| 挖掘速度 | +30% |
| 攻击速度（物品使用速度） | +40% |
| 运气 | +0 |
| 免疫摔落伤害 | 启用 |
| 免疫击退 | 启用 |
| 远程武器不消耗弹药 | 启用 |

**阶段限制**：开启后加成随进度分三档放大——肉山前 / 肉山后 / 月亮领主后，各档系数可调；关掉则开局直接获得全部力量。

**解锁机制**：免疫摔落、免疫击退、不耗弹药这三项，可以选择「开局即解锁」，也可以选择「每击败一个不同的 Boss 随机解锁一项，三个解锁全部」。

## 新增物品

| 物品 | 效果 |
| --- | --- |
| **初始物品袋** | 右键打开，获得石头、生命水晶、魔力水晶、各类原版药水。每个角色第一次进入任意世界可领取一次 |
| **宝物魔镜** | 传送到随机一个**未开启的宝箱**旁，并显示剩余宝箱数量与分布；右键切换为花之魔镜 |
| **花之魔镜** | 传送到随机一个**世纪之花花苞**，并显示剩余花苞数量；右键切回宝物魔镜 |
| **NPC 监狱建造器** | 在光标位置一键搭建 NPC 监狱，可选随机建材（还能限制只使用肉前材料） |

> 用宝物魔镜在骷髅王前随机传进地牢，后果自负。

## 机制改动（全部可配置）

### 战利品与合成

- **战利品倍率**：NPC 掉落数量翻倍，额外份数可选「全部随机 / 全部指定 / 首件指定其余随机」修饰语（钱币特意排除）
- **合成材料消耗**：按百分比缩放所有配方所需材料，最低 1%
- **额外宝箱物品**：新建世界时按箱子类型追加「主要物品」
- **地牢礼物箱**：新建世界时在地牢入口生成一个上锁金箱，内含若干武器

### 战斗

- **低血量斩杀**：非 Boss 与 Boss 分别设置斩杀阈值
- **无敌帧开关**：玩家 / 非玩家各自独立关闭
- **饰品词条同步**：以第一个饰品栏为模板，把词条复制到其余所有饰品栏与装饰栏
- **首次获得奖励**：落星 → 传送药水、工具腰带 → 建筑师发明背包、闪电靴 → 秒表、猛爪手套 → 每秒伤害计数器
- 5 种水母敌怪追加掉落「整蛊坐垫」

### 装备与背包

- **容器饰品生效**：背包、虚空保险库、猪猪存钱罐、保险箱、护卫熔炉里的饰品视为已装备，各自独立开关（灵感来自 Fargo's Equipable Inventory）
- **万剑齐发**：使用武器时同步发射背包内其他武器的射弹，排除部分召唤武器与特殊射弹武器（默认关闭）

### 探索与采集

- **磁力拾取**：按快捷键（默认 `Z`）把全图掉落物传送到身边
- **快捷获取**：把鼠标悬停的物品直接拿到最大堆叠
- **钓鱼**：额外抛出多条鱼线（最多 +50 条）
- **任务鱼**：任意水域钓出今日任务鱼、任意时间钓出当前环境任务鱼、无视困难模式限制
- **破裂地牢砖**：破坏一块即连锁清理整片，不留残留
- **NPC 商店**：无视条件限制出售全部商品（旅商除外）
- **节日开关**：一键开启圣诞节 / 万圣节

### 界面与特效

- **物品名字 / 伤害类型文字特效**（灵感来自 Enhanced Item Text）
- **召唤物数量显示**：召唤法杖与状态栏显示 `3/15（剩余 4 格）`
- **显示敌怪实时血量**：头顶显示 `当前生命 / 最大生命`
- **彩蛋**：开启后发散彩虹粒子攻击敌人，被命中的非 Boss 敌怪最大生命减半；角色名用纯数字时另有一个彩蛋

## 配置

游戏内 **设置 → 模组 → 宇宙增幅器**，共两个配置页：

| 配置页 | 类 | 管什么 |
| --- | --- | --- |
| 饰品配置 | `LLLConfig` | 增幅器各项数值、阶段系数、界面显示 |
| 游戏机制更改 | `LLLServerConfig` | 上表所有机制的总开关与参数 |

有些机制（世界生成、宝箱物品）**只对新建世界生效**，旧世界不会追溯。

## 快捷键

在 **设置 → 控制** 中绑定：

- 磁力拾取（默认 `Z`）
- 获取鼠标悬停物品

## 目录结构

```
LLL/
├── Items/          物品：魔镜、物品袋、监狱建造器、工具
├── Buffs/          宇宙增幅器状态增益
├── Players/        ModPlayer：属性加成、自动重铸、钓鱼任务、词条同步
├── NPCs/           GlobalNPC：掉落、斩杀、Boss 解锁进度
├── Systems/        ModSystem：战利品、宝箱、商店、特效、任务鱼、无敌帧
├── Tiles/          物块
├── WorldGen/       世界生成（地牢礼物箱）
├── Projectiles/    弹幕
├── Localization/   中 / 英本地化（hjson）
├── build.txt       模组元数据：显示名、作者、版本
├── description.txt 游戏内模组简介
└── LLL.csproj      项目文件
```
